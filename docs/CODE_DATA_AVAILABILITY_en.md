# Data and code availability (draft for manuscript)

Copy/adapt into the English Word manuscript:

---

Code for additive B-spline IPP models, fair residual deep-interaction probes, evaluation metrics (including COR), and figure generation is available at https://github.com/Akakk1/KAN_Maxent (software: MIT License; release tag `ms-submission`). The Python package `kanmaxent` installs with `pip install -e .`. Pre-computed metrics tables and figures are under `results/`. Presence-only and presence–absence tables under `data/nceas/` are a working copy of Elith et al. (2020), licensed **CC BY-NC 4.0** (not MIT): attribution required, non-commercial use only. Optional R `maxnet` baselines require `maxnet` 0.1.4 (`docs/r_dependencies.md`).
